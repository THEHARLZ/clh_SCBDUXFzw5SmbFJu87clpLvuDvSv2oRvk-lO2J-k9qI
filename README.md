# ⚡ Flux Capacitor Calculator

> "Roads? Where we're going, we don't need roads." - Doc Brown

## 🚗 About

Welcome to the **Flux Capacitor Calculator** - a project inspired by the iconic "Back to the Future" trilogy! This tool helps you calculate the energy requirements for your time-traveling DeLorean.

Remember: You need exactly **1.21 gigawatts** to power the flux capacitor!

## 🎬 Characters

- **MARTY** - Marty McFly, our time-traveling hero
- **DOC** - Dr. Emmett "Doc" Brown, the eccentric inventor

## 🔧 Usage

```bash
python flux_capacitor.py
```

## ⚡ Requirements

- Python 3.6+
- A DeLorean (optional, but recommended)
- Plutonium or a bolt of lightning
